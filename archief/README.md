# Archief (niet gepubliceerd)

Deze map wordt door `deploy-exclude.txt` niet op de website gezet.

- `pages/`: pagina's die zijn verborgen (o.a. verborgen projecten en de uitgeschakelde webwinkel), met behoud van de oorspronkelijke inhoud.
- `images/`: afbeeldingen van verborgen projecten en ongebruikte bestanden. Een project terugzetten: bestanden terug naar `images/` verplaatsen, `status` in `tools/projects/hidden.json` wijzigen en `python3 tools/projects/render.py` draaien.

Verborgen projecten zijn pas weer publiek te maken nadat de eigenaar de beschrijving en de foto's heeft bevestigd.
